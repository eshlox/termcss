term.css

A minimal, classless CSS framework with terminal aesthetics. This paragraph tests bold text, italic text, links, inline code, marked text, and small text.

Typography

Body text in monospace at a comfortable line-height. Long paragraphs wrap at full width - no max-width, the user controls column width by resizing the browser, just like a terminal.
